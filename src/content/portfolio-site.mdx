## Overview

This site itself. A React + Vite single-page app with an Apple-style "museum
gallery" design: full-bleed tiles that alternate light and dark, one accent blue,
and lots of quiet space.

## The one 3D moment

The landing hero runs a slow, monochrome point-cloud in three.js — a quiet nod to
the quant work — and freezes to a still frame when the visitor prefers reduced
motion. Everything below the hero stays flat and calm.

## Content

Project write-ups (like this one) are MDX files with frontmatter, KaTeX math, and
syntax-highlighted code. The frontmatter builds each room's tiles automatically,
so the same facts are never typed twice.
